**Data availability. ** It contains road-condition labels, multi-source sensor time series and per-sample anomaly annotations, with fields, labelling rules and splits identical to those used in the experiments reported here. Owing to its size (approximately 350 GB, including the raw recordings from all road conditions), the complete dataset far exceeds GitHub's 100 MB per-file limit and recommended repository size and cannot be hosted there in full. To keep the reported results verifiable and reproducible, the validation split is released first in this repository: it retains every validation sample without subsampling or truncation, at the original 2560x1440 resolution and with the sensor and annotation fields unchanged, and is sufficient to reproduce every validation-set result. To keep the repository within GitHub's size guidance, the road images are stored as JPEG (quality 92, 4:4:4 chroma, no resampling) instead of the original lossless PNG; the PNG originals are available from the corresponding author on request. The full dataset (training and test splits, together with the raw recordings) will be released, at which point the download link in this repository will be updated. In the interim, requests for the complete dataset for peer review, replication or benchmarking can be sent to the corresponding author using the contact details given in the paper, with a brief statement of intended use; requests are answered within 7 working days.
